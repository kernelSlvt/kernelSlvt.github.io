# GitHub Pages CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add verified artifact-based GitHub Pages deployment and remove generated site output from source tracking.

**Architecture:** Pull requests and pushes run deterministic generator checks on Python 3.11 and 3.13. Main-branch deployments repeat verification, upload `docs/` as a Pages artifact, deploy with least-privilege permissions, and smoke-test the production domain.

**Tech Stack:** GitHub Actions, Python 3.11/3.13, unittest, actionlint, Dependabot, GitHub Pages.

**Spec:** `plans/2026-08-26-pages-ci-spec.md`

## Global Constraints

- Preserve `https://sarrthak.com`, all public routes, article prose, and visual output.
- Pin every GitHub Action to a full immutable commit SHA.
- Do not commit, push, or mutate live GitHub Pages settings.
- Keep `docs/` as the local generator output while removing it from Git tracking.
- CI and deployment must run the same generator verification boundary.
